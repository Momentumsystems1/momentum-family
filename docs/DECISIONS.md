# Decisiones de producto

- No se presenta como control parental.
- La visibilidad de ubicación es mutua y consentida.
- El administrador configura permisos y alertas por miembro/dispositivo.
- Azure se limita inicialmente a Azure Maps.
- Ningún secreto se almacena en GitHub ni dentro de la app.
- No se añaden funciones avanzadas hasta probar dos teléfonos reales compartiendo ubicación.
